# SOL · Solar System Explorer

Interactive 3D solar system built with Three.js (single `index.html`, textures embedded).

## Features
- 8 planets orbiting the Sun with real orbital periods, adjustable time speed + pause
- Real Earth map (city lights, clouds, Moon) with country labels (Philippines, Japan, USA, ...)
- Moons: Moon, Phobos, Deimos, Io, Europa, Ganymede, Callisto, Titan
- Click any world to fly to it, Orbit / Free flight modes, zoom +/-, fullscreen

## Run
Open `index.html` in a browser (needs internet for the Three.js CDN), or deploy on GitHub Pages / Vercel.

## Deploy on GitHub Pages
Repo Settings -> Pages -> Deploy from branch -> `main` / root.
